# Surfare privacy notice

The notice appears after the intro and before the tour invitation. Seven
acknowledgments start unchecked. Select all is optional; individual choices
remain editable. Agreement is required for checks, camera access, and the tour.
Not now allows browsing without recording acceptance. Privacy & terms in the
footer reopens the notice and offers Clear saved acknowledgment.

Only the notice version and acceptance timestamp are stored in this browser.
This is a local acknowledgment preference, not a server-side consent audit log.
Changing NOTICE_VERSION prompts visitors to acknowledge the updated notice.
Blocked storage falls back to acknowledgment for the current page session.

Online URL checks remain off by default. Acknowledgment does not enable them.
The included lookup worker uses Cloudflare and Google Safe Browsing; messages
and images stay local for that lookup. URLs and signal excerpts can contain
personal data, so minimization must not be described as guaranteed anonymity.
Feedback is submitted through EmailJS only when the user sends the form.

The intended OpenRouter AI and learning features are not implemented in this
checkout. The notice describes the separate choices they will require rather
than claiming those features or their privacy controls already exist. Before
enabling them, present the exact signal payload, selected model and provider,
retention/training rules, and separate optional permission for personal data
and feedback reuse. Enforce those permissions on every request; never use the
seven-item acknowledgment as authorization for these optional purposes.

## Details needed to finalize the legal notice

- Identify the personal information controller and its contact channel. Set
  VITE_PRIVACY_OPERATOR and VITE_PRIVACY_EMAIL to display verified details.
- Confirm the actual hosting, model, URL-checking, and feedback recipients,
  including destinations and any international transfers.
- Establish retention/deletion periods for provider logs, recipient mailboxes,
  any feedback dataset, and any future server-side consent records.
- Confirm lawful bases, security practices, rights-request handling, and the
  selected providers' terms before publishing as a finalized legal policy.

No compliance certification or guarantee of anonymous data, zero retention,
perfect detection, or perfect security is made by this interface.
